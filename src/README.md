# Source Code Directory

This is the main source directory for the TaskMasterAI frontend application, primarily written in TypeScript and React.

Key contents include:
- **App.tsx**: Main application entry point and layout.
- **index.css** / **login.css**: Global and login page styles using Tailwind CSS.
- **lib/**: Helper libraries (API wrappers, utilities, payment integration).
- **utils/**: Shared React components or utility functions.
- **status/**: Status page or related status components.

## Getting Started

1. Install dependencies:  
   ```bash
   npm install
   ```
2. Start development server:  
   ```bash
   npm run dev
   ```

## Structure

- `components/`: React UI components (not shown in this listing, but likely present).
- `lib/`: API and utility functions.
- `utils/`: Icons and shared helpers.
- `status/`: Status-related UI and logic.
