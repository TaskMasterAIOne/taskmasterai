# src/utils

This folder contains shared utilities and React components used throughout the TaskMasterAI app.

## Contents

- **Icons.tsx**: Collection of reusable SVG icon components for UI consistency.

## Usage

Icons can be imported and used in your React components:

```tsx
import { Icons } from './utils/Icons';

<Icons.logo />
<Icons.dashboard />
```
