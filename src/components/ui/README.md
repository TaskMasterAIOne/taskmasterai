# src/components/ui

This folder contains reusable UI primitives and headless components, designed to be accessible and composable across the app.

## Example Components

- **button.tsx** – Polymorphic button component with variant and size support.
- **dialog.tsx** – Modal dialog implementation using Radix UI.
- **popover.tsx** – Popover component using Radix UI.

## Usage

Import these components for consistent UI patterns:

```tsx
import { Button } from '../ui/button';
import { Dialog } from '../ui/dialog';
import { Popover } from '../ui/popover';
```
