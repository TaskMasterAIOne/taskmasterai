# src/components/login

This folder contains the UI and logic for user authentication.

## Key Components

- **login-form.tsx** – Main login form supporting email/password and Google sign-in.
- **login-header.tsx** – Header and introductory text for the login view.
- **login-footer.tsx** – Footer with sign-up and legal links.
- **login-container.tsx** – Styled container for wrapping login content.
- **google-login-button.tsx** – Button for Google OAuth login.

## Usage

These components are composed to build the login page and handle all authentication-related UI flows.
