# src/status

This directory contains status page components and related logic.

## Key Component

- **Status.tsx**: React component for displaying application status, incident history, and streaming updates from the AI API.

## Features

- Shows operational status, outage incidents, and history.
- Streams updates from backend or AI endpoints.
- Integrates with icons from the UI library.
